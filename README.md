# Precariat Opportunity Engine

An AI-powered platform that helps independent filmmakers discover and apply to grants, festivals, labs, and fellowships.

Built by **Precariat Productions** (Ryan Guiterman & Sam Ellison).

## 🚀 First time deploying? 

**Read [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md)** — a complete step-by-step walkthrough that assumes zero technical knowledge. You'll have a live app in about 20 minutes.

## Features

- 📁 **Project Materials Upload** — Attach screenplays, pitch decks, look books, and treatments. The AI reads them directly during analysis
- 🔬 **Project Intelligence** — Deep AI analysis of each project's artistic merits and market positioning
- 🔍 **Smart Discovery** — Analysis-powered search for grants, festivals, labs, and fellowships
- 📝 **Auto-Generated Applications** — Hand-tailored cover letters, project statements, and more
- 📅 **Deadline Tracking** — Visual timeline with calendar sync
- 💳 **Payment Safety** — 3-step approval flow with spending controls
- 💾 **Persistent Storage** — All data saved locally in your browser

## Quick Reference

**Run locally:**
```bash
npm install
npm run dev
```
Open http://localhost:3000

**Deploy:** Push to GitHub, import to Vercel, click Deploy. See the deployment guide for detailed steps.

**Configure:** After deployment, open the app and go to the **Profile** tab to enter your Anthropic API key.
